# Configuration requise pour le cours en direct pour l’instructeur

## Se tenir prêt avec Adobe Connect

Les sessions en direct seront menées à l’aide d’Adobe Connect. Veillez à suivre ces points de contrôle pour éviter des problèmes techniques au cours de la session en direct :

1. Exécutez ce [test de diagnostic](https://training.adobeconnect.com/common/help/en/support/meeting_test.htm) pour vous assurer qu’Adobe Connect fonctionne correctement sur votre système.
1. Passez en revue les [spécifications techniques](https://helpx.adobe.com/fr/adobe-connect/connect-tech-spec/12-10-technical-specifications.html) d’Adobe Connect.
1. Vous pouvez rejoindre Adobe Connect par le biais d’un navigateur ou de l’application de bureau. Si l’application de bureau est déjà installée et que vous rencontrez des problèmes, désinstallez l’application Adobe Connect et réinstallez-la à l’aide de la dernière version fournie [ici](https://helpx.adobe.com/in/adobe-connect/connect-downloads-updates.html).

Vous trouverez votre lien de salle de réunion virtuelle personnalisé dans votre invitation de calendrier. Le jour de l&#39;entraînement, nous vous recommandons de lancer le lien 5-10 minutes avant le début du cours.

Ressources supplémentaires :

* [Centre d’aide : assistance technique](/help/main-guide/technical-support.md)
* [Blog d’assistance Adobe Connect](https://blogs.connectusers.com/connectsupport/adobe-connect-best-practices/)

## Configuration matérielle requise

* Ordinateur ou ordinateur portable avec clavier et souris
* 8 Go de RAM ou plus pour des performances optimales du navigateur
* Ensuite, le moniteur externe est préféré avec une résolution minimale de 1 280 x 768 pixels
* Connexion Internet de 100 Mbps ou plus

## Configuration logicielle requise

* Les navigateurs web recommandés sont Chrome ou Firefox
* Accès à **écran de connexion** uniquement pour [Adobe CX Enterprise](https://experience.adobe.com/#/home). Les informations de connexion seront fournies pendant la formation
* Accéder à un éditeur de texte
* Disposer d’un programme pour extraire les fichiers d’archive (.zip)
* disposer d’un programme pour lire les fichiers PDF tels que [Adobe Reader](https://get.adobe.com/reader/) ;

>[!NOTE]
>
>Ne pas se connecter Vérifiez simplement que vous pouvez accéder au lien dans votre navigateur sans que le réseau de votre entreprise ne le bloque. Il se peut que le message « Votre Adobe ID n’est pas lié à vos comptes de solution Adobe Experience Cloud » s’affiche, ce qui est normal. Les liens ne sont pas destinés aux élèves pour accéder à quoi que ce soit à l’avance jusqu’à votre arrivée en classe. Le premier jour du cours, votre instructeur vous fournira les informations d&#39;identification pour vous connecter.
