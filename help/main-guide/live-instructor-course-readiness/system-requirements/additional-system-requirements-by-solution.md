# Configuration requise supplémentaire par solution

## Développement de Adobe Experience Manager Edge Delivery Services

Un compte GitHub public personnel est requis.

## Adobe Experience Manager Sites

Les étudiants auront accès au compte de la société Premium Learning Adobe Experience Manager pendant toute la durée de la classe pour terminer les laboratoires de cours.

Pour les cours techniques sur Adobe Experience Manager, utilisez un logiciel de machine virtuelle appelé **[!DNL ReadyTech]**. Avant le cours, veillez à :

1. Effectuez [&#x200B; Vérification Préalable Des Performances &#x200B;](https://adobe.instructorled.training/system-precheck)
1. Effectuez la prévérification de l’accessibilité et vérifiez l’accès à l’[[!DNL ReadyTech] écran de connexion](https://axis.readytech.com/#/login) uniquement (ne vous connectez pas).

## Adobe Campaign

Le client Campaign est une application Windows uniquement. Si vous ne disposez pas d’une machine Windows pour installer le client Campaign, un environnement virtuel appelé **[!DNL ReadyTech]** vous sera fourni pendant la classe.

Si vous ne disposez pas d&#39;un ordinateur Windows ou de la capacité d&#39;installer un logiciel, assurez-vous de :

1. Effectuez [&#x200B; Vérification Préalable Des Performances &#x200B;](https://adobe.instructorled.training/system-precheck)
1. Effectuez la prévérification de l’accessibilité et vérifiez l’accès à l’[[!DNL ReadyTech] écran de connexion](https://axis.readytech.com/#/login) uniquement (ne vous connectez pas).

## Adobe Experience Platform

Certains cours techniques d’AEP utilisent **Postman** pour les activités liées aux API. Si vous n&#39;avez pas la possibilité de l&#39;installer sur votre ordinateur, vous recevrez une machine virtuelle appelée **[!DNL ReadyTech]** pendant le cours.

Si vous ne pouvez pas installer de logiciel, veillez à :

1. Effectuez [&#x200B; Vérification Préalable Des Performances &#x200B;](https://adobe.instructorled.training/system-precheck)
1. Effectuez la prévérification de l’accessibilité et vérifiez l’accès à l’[[!DNL ReadyTech] écran de connexion](https://axis.readytech.com/#/login) uniquement (ne vous connectez pas).

## Adobe Target

Nous vous recommandons de télécharger et d’installer ces extensions Chrome :

* [Adobe Experience Platform Debugger](https://experienceleague.adobe.com/fr/docs/experience-platform/debugger/home)
* [Compositeur d’expérience visuelle Adobe Target](https://chromewebstore.google.com/detail/adobe-experience-cloud-vi/kgmjjkfjacffaebgpkpcllakjifppnca?pli=1)
